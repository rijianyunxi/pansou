# 上游管理工作台（第一阶段）

入口：`/upstreams`，搜索页导航也有「上游管理」。

## 启动

```sh
NUXT_TELEMETRY_DISABLED=1 NITRO_PRESET=node-server pnpm dev --host 127.0.0.1 --port 3000
```

建议仅绑定回环地址。探测 API 在生产构建中固定返回 403，不应将本工作台作为公网管理服务。

## 本版能力

- 12 个内置独立地址（10 个插件），混合盘的三个来源分别列出。
- 单个/顺序批量探测、停止后续测试、最近状态与请求总耗时。
- 关键词调试、请求参数预览、HTTP/业务状态、原始响应、每步轨迹和统一结果。
- 自定义 GET/POST、JSON/HTML 来源配置草稿，编辑和删除。
- JSON 点路径字段映射，可选嵌套链接数组；样本预览输出既有 `SearchResult[]`。
- 浏览器 localStorage 保存草稿、映射覆盖与最近一次报告；不是共享数据库。

## 状态语义

- **可用**：请求与已实现的适配器解析通过。零结果不等于不可用，也不保证结果相关性或分享链接有效。
- **异常**：网络/TLS、HTTP、业务状态或数据结构校验失败；HTTP 200 不代表业务成功。
- **待确认**：HTML 仅可达，或未识别专用结果结构；不宣称完整搜索链路成功。
- **未检测**：当前浏览器没有本地探测记录。不会自动探测或伪造健康数据。

混合盘系列、极客盘、趣盘搜使用 JSON 映射；Nyaa 使用 HTML 解析；PanSearch 先读取 buildId，再请求 Next.js 数据。多多、盘他、蜡笔、海盗湾、学习指南目前仅探测入口页，不执行原插件的详情抓取链路。工作台不是现有插件所有分页、重试、过滤行为的完全复刻。

## 安全和边界

- 服务端仅接受内置来源 ID 和 1–100 字符的关键词；不能传入自定义 URL。
- 每次探测最长 12 秒，最多两个并发；不重试、不跟随重定向，不关闭 TLS 校验。
- 单次响应最大 1 MiB；界面原文最多 100,000 字符，本地持久化最多 30,000 字符，截断会标识。
- 搜索密码已配置时，沿用既有 Cookie 鉴权；先到搜索页解锁。
- 映射不执行表达式或用户脚本，禁止原型属性路径，输出过滤危险链接协议。
- 自定义 URL **只保存草稿，不发请求**。映射修改**只作用于样本预览，不发布到搜索服务**。
- 批量参与开关只影响此工作台，独立于搜索页来源开关。
- 原始响应和提取码会留在当前浏览器；不要把密钥放在地址或样本中。

## 后续接入点

- `config/upstreams.ts`：内置目录、请求定义和探测报告类型。
- `utils/upstreamAdapter.ts`：安全字段映射与统一输出。
- `server/core/services/upstreamProbe.ts`：受限探测执行器。
- `server/api/upstreams/probe.post.ts`：开发模式、鉴权和并发边界。
- `pages/upstreams/index.vue`：列表、调试、适配器及本地持久化。

后续动态执行/发布需要另做服务端配置仓库、管理鉴权、密钥存储、地址与 DNS/IP 安全检查，再将适配器注册到正式搜索调度；不要直接移除白名单变成任意 URL 代理。

## 验证

```sh
pnpm test
NITRO_PRESET=node-server pnpm build
```

新增单测覆盖字段路径、统一输出、协议过滤、结果限额、业务 414、网络错误、禁止重定向、HTML 待确认、Nyaa/PanSearch 解析和响应大小限制。
